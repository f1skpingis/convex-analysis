\subsubsection{CO: 3.5}
\textbf{Running average of a convex function. Suppose $f: \mathbb{R} \to \mathbb{R}$ is convex, with $\mathbb{R}_+ \subseteq \operatorname{dom}f$. Show that its running average F, defined as}
\[
    F(x) = \frac{1}{x}\int_0^xf(t)dt
\]
\textbf{is convex. \textit{Hint}. For each $s$, $f(sx)$ is convex in x, so $\int_0^1 f(sx)ds$ is convex.}

This can be shown by a change of variable.
Change integration variable from $t \to xt$. 
This changes the integration measure to $xdt$ and the bounds from $(0, x)$ to $(0, 1)$.
We get
\[
    F(x) = \frac{1}{x} \int_0^1f(xt)xdt = \int_0^1 f(xt)dt.
\]
This is exactly the quantity said to be convex in the hint.

\subsubsection{CO: 3.6}
\textbf{Functions and epigraphs. When is the epigraph of a function a halfspace? When is the
epigraph of a function a convex cone? When is the epigraph of a function a polyhedron?}

\textit{Halfspace}. The epigraph of a real valued function is the set 
\[
    \operatorname{epi} f = \{ (x, t) \in \operatorname{dom}f \times \mathbb{R} \mid f(x) \leq t \}
\]

The description of a halfspace in terms of an inequality is $a^T x \leq b$.
Thus if we take $f(x) = a^T + b$ in the epigraph definition above, we see that any affine function has a halfspace as epigraph.

\textit{Convex cone}. If the epigraph is a convex cone that means that $(x, t) \in \operatorname{dom} f \implies (\lambda x, \lambda t) \in \operatorname{dom} f$.
That means that if $f(x) \leq t$ then $f(\lambda x) \leq \lambda t$.

Now, fix a point on the boundary on the epigraph, $(x, t)$ such that $f(x) = t$.
Scale that point by $lambda$, then we get $f(\lambda x) \leq \lambda t = \lambda f(x)$.
Now, we do it in the reverse direction from $\lambda x \to x$.
Pick $(\lambda x, r)\in \operatorname{epi} f$ such that $f(\lambda x) = r$.
This means that $f(\frac{\lambda}{\lambda} x) = f(x) \leq \lambda r = \lambda f(\lambda x)$.
Bringing these inqeualities together, we see that 
\[
\lambda f(x) \leq f(\lambda x) \leq \lambda f(x)
\] 

This can only hold if $f(\lambda x) = \lambda f(x)$, a so called \textit{homogeneous} function of degree one.

\textit{Polyhedron}. A polyhedron is an intersection of halfspaces. 
This means that the function is a convex piecewise affine function. 
I claim this implies that the function is of the form $f(x) = \max_i a_i^T x + b_i$.

\textit{Proof}. Pick a point $x_i$ in the interior of some region $P_i$ where the affine piece is $\ell_i(x) = a_i^T x + b_i$.
Since $a_i$ is the gradient there, $\ell_i$ defines a supporting hyperplane of the epigraph, i.e. $f(x) \geq \ell_i(x), \quad \forall x$.
This argument can be repeated for all affine pieces and thus $f(x) \geq \ell_i(x), \quad \forall i$. 
But on the other hand, since at every $x$ some piece $j$ is active, meaning
\[
    f(x) = \ell_j(x)
\]
we conclude
\[
    f(x) = \max_i \ell_i(x).
\]
\hfill$\square$
\subsubsection{CO: 3.15}
\textbf{A family of concave utility functions. For $0 < \alpha \leq 1$ let}
\[
    u_\alpha(x) = \frac{x^\alpha - 1}{\alpha},
\]
\textbf{with $\operatorname{dom} u_\alpha = \mathbb{R}_+$. We also define $u_0(x) = \log x$ (with $\operatorname{dom} u_0 = \mathbb{R}_{++}$).}
\begin{enumerate}[label=(\alph*)]
    \item \textbf{Show that for $x > 0$, $u_0(x) = \lim_{\alpha \to 0} u_\alpha(x)$.}
    \item \textbf{Show that $u_\alpha$ are concave, monotone increasing, and all satisfy $u_\alpha(1) = 0$.}
\end{enumerate}
\textbf{These functions are often used in economics to model the benefit or utility of some quantity of goods or money.
Concavity of $u_\alpha$ means that the marginal utility (i.e., the increase in utility obtained for a fixed increase in the goods) decreases as the amount of goods increases.
In other words, concavity models the effect of satiation.}
\begin{enumerate}
    \item[a)] I can think of two ways to show this, both of which are quite simple.
    The first one is using L'Hôpital's rule and the second is via the Taylor expansion of $u_\alpha$.
    L'Hôpital's rule is (assuming the limits exist and so on)
    \[
        \lim_{x \to 0}\frac{f(x)}{g(x)} = \lim_{x \to 0} \frac{f'(x)}{g'(x)}
    \]
    Plugging in our function
    \[
        \lim_{\alpha \to 0} \frac{x^\alpha - 1}{\alpha} = \lim_{\alpha \to 0} (\log x) x^\alpha = \log x
    \]
    Pretty clean. 
    Now, looking the the Taylor expansion instead, we have
    \[
        \frac{x^\alpha - 1}{\alpha} = \frac{e^{\log x \alpha} - 1}{\alpha} = \frac{\sum_{k=0}^{\infty} \frac{(\log x \alpha)^k}{k!} - 1}{\alpha}
    \]
    Picking out the terms that are at most of order $\alpha^1$, we have
    \[
        u_\alpha(x) = \frac{1 + \log x \alpha - 1 + O(\alpha^2)}{\alpha} = \log x + O(\alpha)
    \] 
    Letting $\alpha \to 0$ gives us the desired result.
    \item[b)] 
    That they all satisfy $u_\alpha(1) = 0$ is trivial. 
    To show concavity and monotone increasing, we inspect the derivatives.
    \[
        u'_\alpha(x) = x^{\alpha - 1} \geq 0,
    \]
    \[
        u''_\alpha(x) = (\alpha - 1)x^{\alpha - 2} \leq 0.
    \]
    As we see, the first derivative is positive and the second derivative is negative, i.e. the function is monotone increasing and concave.
\end{enumerate}

\subsubsection{CO: 3.16}
\textbf{For each of the following functions determine wheterh it is convex, concave, quasiconvex, or quasiconcave.}
\begin{enumerate}[label=(\alph*)]
    \item $f(x) = e^x - 1$. By computing the second derivative of $f$, we get
    \[
        f''(x) = e^x > 0
    \]
    which means $f$ is convex.
    It is thus also quasiconvex and infact, since it is single valued and monotone, it is quasiconcave too.
    \item $f(x_1, x_2) = x_1 x_2$ on $\mathbb{R}_{++}^2$.
    Let's compute the Hessian
    \[
        \nabla^2 f(x_1, x_2) = \begin{pmatrix}
            0 & 1\\
            1 & 0
        \end{pmatrix}.
    \]
    The Hessian has eigenvalues $\pm 1$ and is thus neither positive nor negative definite. 
    This means that it cannot be convex or concave. 
    As for quasiconvexity or quasiconcavity, let's have a look at the superlevel sets:
    \[
        x_1x_2 \geq \alpha
    \]
    This can be interpreted as the epigraph (since $x_1, x_2 > 0$) of $g(x) = \alpha / x$ which is a convex function.
    That in turn means the epigraph and consequently the superlevel sets of $f$ are convex meaning the function is quasiconcave.
    Since the complement, $\mathbb{R}^n \backslash \{x_1x_2 \geq \alpha\}$, of a convex set (which is not empty, the whole space or a halfspace) is not convex, the function is not quasiconvex.
    
    \item Let's look at the Hessian
    \[
        \nabla^2 f(x_1, x_2) = \begin{pmatrix}
            \frac{2}{x_1^3x_2} & \frac{1}{x_1^2x_2^2}\\
            \frac{1}{x_1^2x_2^2} & \frac{2}{x_1x_2^3}
        \end{pmatrix}
    \]
    All pricipal minors (the (1,1)-entry and determinant) are positive over the entire positive orthant, so this is positive definite.
    The (1,1)-entry is trivially positive, let's check the determinant,
    \[
        \det \nabla^2 f(x_1, x_2) = \frac{4}{x_1^4x_2^4} - \frac{1}{x_1^4x_2^4} = \frac{3}{x_1^4x_2^4} > 0
    \]
    Thus the function is convex and quasiconvex (i.e. not concave).
    To check whether or not it is quasiconcave, we check the superlevel sets,
    \[
        \frac{1}{x_1x_2} \geq \alpha.
    \]
    This equivalent to
    \[
        \frac{1}{\alpha} \geq x_1x_2
    \]
    which is a sublevel set of $g(x_1, x_2) = x_1x_2$. 
    We just saw that $g$ was not a convex function, meaning the sublevel set isn't convex either, thus meaning the superlevel sets of $f$ are not convex.
    This means $f$ is convex and quasiconvex but niether concave nor quasiconcave. 
    \item Once again, let's inspect the Hessian
    \[
        \nabla^2 f = \begin{pmatrix}
            0 & -\frac{1}{x_2^2}\\
            -\frac{1}{x_2^2} & \frac{2x_1}{x^3_2}
        \end{pmatrix}
    \]
    This matrix is neither positive nor negative semidefinite, since the determinant is negative, $-1 / x^4_2$.
    For a $2\times 2$ matrix that means the eigenvalues must have opposite sign.
    The function is thus neither convex nor concave. 
    What about the superlevel sets?
    \[
        x_1/x_2 \geq \alpha
    \]
    This is equivalent to
    \[
        x_1 \geq \alpha x_2.
    \]
    This is the epigraph of a linear function and thus a convex set (halfspace).
    The complement is the sublevel set which is the naturally also a halfspace and thus a convex set.
    That means the function is both quasiconvex and quasiconcave.
    \item The Hessian is
    \[
        \nabla^2 f(x_1, x_2) = \begin{pmatrix}
            2/x_2 & -2x_1/x_2^2\\
            -2x_1/x_2^2 & 2x_1^2/x_2^3
        \end{pmatrix}
    \]
    It looks a bit complicated but the eigenvalues, $\lambda$, are the solutions of
    \[
        \lambda(\lambda - 2/x_2 - 2x_1^2/x_2^3) = 0
    \]
    This means we have eigenvalues $\lambda = 0$ and $\lambda = 2(x_1^2/x_2^3 + 1/x_2)$.
    These are both nonnegative so the matrix is positive semidefinite.
    It can infact also be seen in this more elegant way; the matrix can be factorized as the outer product of $v = (2/x^3_2)[x_2 - x_1]^T$ with itself.
    That means for any vector $z \in \mathbb{R}^2$, 
    \[
        z^T\nabla^2 f(x_1, x_2)z = z^T v v^T z = (z^T v)^2 \geq 0.
    \]
    The superlevel sets
    \[
        x^2_1/x_2 \geq \alpha
    \]
    are epigraphs of a concave function so not convex.
    The function is only convex and quasiconvex.
\end{enumerate}
